# برنامه‌ریز کارها (نسخه‌ی اولیه)

این مخزن یک پروژه‌ی Flutter است که فقط با GitHub قابل ساخت است؛ لازم نیست Flutter را روی کامپیوتر نصب کنی.

## ساخت APK با GitHub
1. در GitHub یک مخزن جدید بساز.
2. فایل `todolist_github.zip` را از حالت فشرده خارج کن.
3. همه‌ی فایل‌ها و پوشه‌های داخلش را در مخزن GitHub بارگذاری کن (از جمله پوشه‌ی `.github`).
4. به بخش **Actions** مخزن برو و اجرای workflow با نام **Build Android APK** را باز کن.
5. پس از تمام شدن موفق، از بخش **Artifacts** فایل `task-planner-apk` را دریافت کن. داخل آن `app-release.apk` است.

## امکانات
- افزودن، ویرایش و حذف کار
- انتخاب تاریخ شمسی و نمایش ماه‌های فارسی
- تعیین ساعت شروع و پایان (پایان باید بعد از شروع باشد)
- پیوست چند فایل/عکس و نمایش نشان کوچک پیوست در کارت کار
- ذخیره‌ی محلی اطلاعات روی دستگاه
- تب‌های کارها، تقویم و من

## نکته‌های مهم
- این نسخه یک پیاده‌سازی مستقل با الهام از چیدمان تصاویر ارسالی است، نه کپی کد/برند اختصاصی اپ دیگر.
- فایل‌های پیوست در حافظه‌ی داخلی برنامه ذخیره می‌شوند؛ پاک‌کردن داده‌های برنامه یا حذف برنامه ممکن است آن‌ها را حذف کند. فعلاً همگام‌سازی ابری ندارد.
- ساخت موفق APK به وضعیت سرویس‌های GitHub و وابستگی‌های Flutter در زمان اجرا وابسته است. workflow خروجی build را بررسی می‌کند، اما تضمین «بدون هیچ باگ» ممکن نیست؛ قبل از استفاده‌ی جدی، روی گوشی آزمایش کن.
