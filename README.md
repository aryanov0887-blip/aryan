# برنامه‌ریز کارها

پروژه‌ی Flutter با تقویم شمسی، تم تیره‌ی آبی و ساخت APK از طریق GitHub Actions.

## امکانات
- کار با دسته‌بندی (همه، کاری، شخصی، آرزوها + دسته‌های دلخواه)
- زیرکار، یادداشت، پیوست (عکس و فایل)، علامت مهم
- تاریخ شمسی، ساعت شروع و پایان
- یادآوری (سر وقت تا یک روز قبل) با دو نوع: اعلان معمولی و هشدار قوی
- تکرار روزانه، هفتگی و ماهانه
- گروه‌بندی کارها: عقب‌افتاده، امروز، فردا، بعداً، پایان‌یافته
- تب «من»: نقشه سالانه، نمودار دسته‌ها، نمودار هفتگی، نرخ تکمیل، تایمر تمرکز، کارهای ۷ روز آینده

## ساخت APK
بعد از push، در بخش Actions گزینه **Build Android APK** را اجرا کن و از Artifacts فایل `task-planner-apk` را بگیر.
